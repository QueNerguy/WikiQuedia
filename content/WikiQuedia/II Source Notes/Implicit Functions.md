### Implicit Functions
13-05-2025
#### Referencing:
[Wikipedia - Implicit function](https://en.wikipedia.org/wiki/Implicit_function)

#### Synopsis:
An implicit function is a function that is defined by an _implicit equation_, where one of the variables of the function which is also considered the value[^val] of the function is included in the arguments of the function. <br>A non-implicit function would have this variable outside, like $y = f(x) = 2x^2$ where $y$ gives the value of the function, but an implicit function would have the variable inside. For example if $y$ gave the value of the function an implicit function would look like $f(x) = x^2 + y = 0$. Another example would be the equation to a circle $x^2 + y^2 = 1$. <br>Implicit functions always include both a left- and right hand side. The function $f(x, y) = x^2+y$ can't exist without knowing the value of $f(x,y)$, which in turn would bring us to $f(x) = x^2 + y = 0$ for example.





[^val]: What is meant by "value" is equivalent to the saying the height of a function. In a 2D case this would be the $y$ axis/variable, and in 3D the $z$ axis/variable, etc.
