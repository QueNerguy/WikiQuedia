# Range or Interval

### Geometrical interpretation
The term _range_ is used interchangeably with the meaning of the term _[interval](https://simple.wikipedia.org/wiki/Interval_(mathematics))_ in this wiki, to mean the complete set of numbers between a starting and end point. The range $[1, 3]$ will include 2, but also 1.00001. <br>Ranges are usually used to define the output of a function that outputs a variable. The range in this case would be the values this variable can assume to have the function still be valid. See for example [this chapter](Evaluating%20Infinite%20Series#Multivariable%20Case) on evaluating infinite series, where the series will only convergence for a certain _range_ of input values. Every value outside of this range will not give a converging sum, but every possible value inside, no matter how many decimal points it has, will. 
### Definition
A range can be either _open_, _closed_ or _half open_/_closed_.
1. An ___open___ range is a range where the endpoint(s) are _not_ part of the range itself, or not defined ($\infty$ for example). The syntax is: __$( x_1,x_2)$__
2. A ___closed___ range is a range where the endpoints _are_ part of the range itself. The syntax is: __$[x_1,x_2]$__
3. A ___half open___ range is a range that has one open side and one closed side.The syntax is: __$\left\lbrack x_1,x_2\right)$__
The notation $\left\lbrack x_1,x_2\right\rbrack$ just means $\left\lbrack x_1\to x_2\right\rbrack$. <br>Points on a range can be catagorized into 2 groups.
- ___End Points:___ The last and first points on the closed ends of the range. If the range is $\left\lbrack-2,2\right\rbrack$, the end points are $-2$ and $2$.
- ___Interior Points:___ All inner points within the range. If the range is $\left\lbrack-2,2\right\rbrack$, then the interior points are the set $\left(-2,2\right)$. ($\leftarrow$ Thus excluding the endpoints!)

A range can also consist of only integer values (whole numbers, no commas). The notation used in this wiki is $\{x_1, x_2\}$, but outside sources may use $[\![x_1 , x_2]\!]$, or $[x_1 .. x_2]$ to denote the interval.

>[!abstract]
>A range or interval is a set of numbers that includes all possible values between a starting and end point.
