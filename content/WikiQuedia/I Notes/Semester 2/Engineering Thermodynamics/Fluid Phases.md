# Fluid Phases
In thermodynamics we study only the fluid phases of a substance. 


### Changing Phase
When moving from phase to phase, like liquid to gas, the in-between state sees some part of the substance be gas, while some stays liquid. This causes the system to want to increase in size, but the temperature during this transition stays constant. This causes the system to still be able to absorb [heat](Heat), while not changing temperature. This absorbed heat is referred to as [latent heat](https://en.wikipedia.org/wiki/Latent_heat).
