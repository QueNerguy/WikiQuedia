# Domain
### Geometrical Interpretation
 Domains confine a function $f$ to a certain shape or set of points. If the domain $D$ is given by the function $f$, that means that all solutions to other functions that are bound by this domain, are only relevant if the input that gave that value was within the line or area or volume dictated by the domain $D$ out of $f$. <br>For a circle, the domain would be the area the circle encloses, with or without the circle itself. Other domains are usually a combination of two functions, where the domain runs from function 1 to function 2. The domain then, contains all the points that are above function 1, and below function 2.
$$
f_2 \ge D \ge f_1
$$
> [!abstract]
> A domain is a set of coordinates, bound by a function(s).

Domains are usually used as input for functions. 
### Definition
A domain can be either _open_, _closed_ or _half open_/_closed_.
1. An ___open___ domain is a domain where the endpoint(s) are _not_ part of the domain itself, or not defined ($\infty$ for example). The syntax is: __$( x_1,x_2)$__
2. A ___closed___ domain is a domain where the endpoints _are_ part of the domain itself. The syntax is: __$[x_1,x_2]$__
3. A ___half open___ domain is a domain that has one open side and one closed side.The syntax is: __$\left\lbrack x_1,x_2\right)$__
The notation $\left\lbrack x_1,x_2\right\rbrack$ just means $\left\lbrack x_1\to x_2\right\rbrack$. <br>Points on a domain can be catagorized into 2 groups.
- ___End Points:___ The last and first points on the closed ends of the domain. If the domain is $\left\lbrack-2,2\right\rbrack$, the end points are $-2$ and $2$.
- ___Interior Points:___ All inner points within the domain. If the domain is $[-2,2]$, then the interior points are the set $\left(-2,2\right)$. ($\leftarrow$ Thus excluding the endpoints!)
