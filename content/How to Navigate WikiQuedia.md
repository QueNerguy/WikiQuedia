The wiki has 3 folders, each has their own purpose. The main one you'll be using is the [notes](https://quenerguy.github.io/WikiQuedia/I-Notes/) folder.

---


1. __Notes__: This folder contains the summaries. Every summary is organized by what course it belongs to.<br>
2. __Source Notes__: This folder contains short overviews of simple concepts that don't require their own page. <br>I will only create a *source note* to quickly summarize a longer article with the goal of making WikiQuedia easier to read. You can get an overview of these concepts by simply hovering over the link instead of loading a whole Wikipedia page or whatever other source I use. Because of this the source notes are written mostly for use withing this wiki. For a completer overview the *source note* page will also link the original source.<br>
3. __Tags__: These are notes are meant to be used for navigation using their back-links. <br>If you forget or don't know what actual subject you are looking for, but do remember what it is related to, look here to find it by looking at the back-links of the tag note. <br>These notes are also useful for structuring the mind-map graph for easier searching, and you can search for them as key phrase with the search function.
